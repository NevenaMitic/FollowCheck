FollowCheck

FollowCheck is a web application that helps users analyze their Instagram follow relationships using their exported Instagram data.

By uploading their Instagram data export, users can easily identify accounts they follow that don't follow them back, view mutual followers, and get a clear overview of their follower connections.

✨ Features
Upload Instagram follower and following data
Identify accounts that don't follow you back
View accounts you don't follow back
View mutual followers
Analyze follower relationships
Simple and intuitive user interface
Fast data processing
Responsive design
No Instagram login or password required

🔐 Privacy
FollowCheck does not require access to your Instagram account, password, or login credentials.

The application works exclusively with data exported directly by the user from Instagram.

🛠️ Tech Stack
Next.js
React
TypeScript
Tailwind CSS

🎯 About the Project
This project was built to explore data parsing and processing, file handling, client-side application logic, and the development of a clean and user-friendly interface using modern web technologies.

The goal was to create a simple and accessible tool that allows users to better understand their Instagram follow relationships without requiring direct access to their Instagram account.
