## 📖 Overview

**FollowCheck** is a web application that helps users analyze their Instagram follow relationships using their exported Instagram data.

By uploading the data export, you can quickly see which accounts don't follow you back, which accounts you don't follow back, and who your mutual followers are, all in a clear and simple interface.

## ✨ Features

- 📤 Upload Instagram followers and following data
- 🚫 Identify accounts that don't follow you back
- 👀 View accounts you don't follow back
- 🤝 View mutual followers
- 📊 Analyze follower relationships at a glance
- ⚡ Fast data processing
- 📱 Responsive design
- 🎨 Simple and intuitive user interface
- 🔑 No Instagram login or password required

## 🚀 How to Use

1. Request your data from Instagram (**Accounts Center → Your information and permissions → Download your information**) and choose the **Followers and following** data in **JSON** format.
2. Download the export once Instagram notifies you it's ready.
3. Open [FollowCheck](https://instafollowcheck.vercel.app) and upload the `followers` and `following` files.
4. Explore your results.

## 🔐 Privacy

FollowCheck **does not** require access to your Instagram account, password, or login credentials.

The application works exclusively with data exported directly by the user from Instagram.
Everything runs in your browser, so your data is never uploaded or stored. Anonymous, cookieless page-view analytics (Vercel Web Analytics) are used to measure site traffic.

## 🎯 About the Project

This project was built to explore data parsing and processing, file handling, client-side application logic, and the development of a clean, user-friendly interface using modern web technologies.

The goal was to create a simple and accessible tool that allows users to better understand their Instagram follow relationships without requiring direct access to their Instagram account.
